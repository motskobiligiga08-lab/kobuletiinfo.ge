KOBULETIINFO.GE — გაერთიანებული საწყისი ვერსია

რა არის ამ ZIP-ში?
- index.html — მთავარი გვერდი: განცხადებები, კატეგორიები, ძებნა და განცხადების დამატება.
- services.html — მეორე გვერდი: მომსახურების მაძიებლების მოთხოვნები და მოთხოვნის დამატება.
- style.css — საერთო დიზაინი და მობილურზე მორგება.
- app.js / services.js — გვერდების ფუნქციონალი.

სწრაფი ნახვა Mac-ზე:
1. გახსენი ZIP (ორმაგი დაწკაპუნებით).
2. გახსნილ საქაღალდეში index.html-ზე ორჯერ დააწკაპუნე.
3. მეორე გვერდის სანახავად გახსენი services.html.

GitHub Pages-ზე ატვირთვა:
1. გახსენი შენი GitHub repository.
2. ატვირთე ამ საქაღალდის ყველა ფაილი repository-ის მთავარ (root) დონეზე.
3. Commit changes.
4. Settings → Pages-ში შეამოწმე Deploy from a branch, branch: main, folder: / (root).
5. დაელოდე საიტის განახლებას.

მნიშვნელოვანი ტექნიკური შეზღუდვა:
ეს არის დიზაინისა და ფუნქციონალის საწყისი დემო. განცხადებები და მომსახურების მოთხოვნები ინახება მხოლოდ იმავე ბრაუზერის localStorage-ში. სხვა მომხმარებლები მათ ვერ დაინახავენ სხვა მოწყობილობიდან. ფოტოც საჯაროდ არ იტვირთება. რეალური საერთო პლატფორმისთვის შემდეგ ეტაპზე დავაკავშიროთ Supabase (საერთო მონაცემთა ბაზა და ფოტო საცავი), დავამატოთ მოდერაცია, წაშლა/რედაქტირება და უსაფრთხოება.
